## Unified external dependencies

1. **Production storage and server configuration:** user acceptance of pending free Neon technical terms; browser extension Allow access to file URLs or manual secure Vercel environment import. Provision only the authorized free resource, use the actual production origin, initialize/check durable SQL, redeploy, and verify HTTPS auth/APIs. No database or subscription was purchased. No insecure fallback is acceptable.
2. **Revolut X private connection:** user registers their own Ed25519 public key and enters the associated API key/private PEM through the authenticated site after production readiness. Confirm actual EEA/Germany account and scope; a read success does not prove trade permission. IP allowlisting may require available stable egress; no new paid service is authorized.
3. **Optional IBKR connection:** existing authorized account, actual API/data entitlements and a persistent locally authenticated Gateway or explicitly approved alternative. Only then implement/verify its adapter. Do not open a new financial account, accept agreements or buy subscriptions.
4. **Final deployed verification and reporting:** record the real Vercel URL/result, run protected deployed checks and isolated simulation, and push the final checkpoint. Keep actual private-account evidence separate from public feed, mocked adapter, and simulated order evidence.

## Preserved scope decisions

- Next.js App Router/TypeScript, server-only official broker adapters, durable SQL state, one owner's password authentication.
- No financial execution during build or testing. The site's future order path serves the user's manual decisions only; the user individually confirms each real order.
- No false balances, positions, returns, FX totals, tradability or buying power. No promised low-risk profit or guaranteed outcome.
- No background investment bot or continuous broker session in short-lived Vercel functions. Polling runs while the app is open; market outages/age remain visible.
- No other project changes or destructive resource operations. No paid plan, brokerage account opening, financial agreement, or funds transfer.
- The prior conversation heartbeat stays **paused**; no ongoing automation was enabled. Work after this session requires a new execution, not an implied promise of continued activity.
