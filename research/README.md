# محاكاة مرصاد البحثية

هذا المسار مستقل عن Next.js وقاعدة بيانات التطبيق ومسارات أوامر الوسيط. لا يستورد أي كود من `src` ولا يقرأ ملفات البيئة أو مفاتيح الوسيط. لا يرسل أوامر مالية. لا يضيف تبويبًا وهميًا إلى حساب الوسيط.

## تجربة مرجعية v1

- BTC-EUR، شموع ساعة واحدة مكتملة من بيانات Revolut X العامة لمنطقة EEA.
- نافذة بحث تاريخية متوسعة تبدأ 1 سبتمبر 2026. الاختيار لغرض اختبار النظام، وليس توصية استثمارية أو نتيجة تحسين على البيانات.
- تقاطع المتوسط البسيط 10 فوق 30: دخول افتراضي عند افتتاح الشمعة التالية. الخروج عند التقاطع المعاكس أو بعد 48 شمعة، عند الافتتاح التالي المتاح. صفقة واحدة دون اقتراض أو مضاعفة.
- رصيد افتراضي 1000 EUR، مبلغ ثابت 100 EUR لكل دخول. رسوم مفترضة 10 نقاط أساس لكل جانب وانزلاق مفترض 5 نقاط أساس لكل جانب؛ ليست أسعار رسوم مؤكدة للوسيط.
- لا تغلق المراكز المفتوحة قسرًا في نهاية العينة. تتضمن قياسات رأس المال تقييمها عند إغلاق كل شمعة. لا تنفيذ افتراضي على شموع بلا حجم، ولا ملء اصطناعي لفجوات البيانات.
- 30 نتيجة جديدة أو 14 يومًا محفز للمراجعة التنظيمية، لا دليل كفاية إحصائية ولا أمر تغيير. أي تعديل له نسخة ودفعة جديدتان. تُحفظ النتائج السابقة ولا يُعلن التوسع بناء على عينة واحدة.

## التشغيل

```sh
node --test research/engine.test.mjs
node research/run.mjs
```

لا يحتاج التشغيل تثبيت حزم أو إعداد بيئة التطبيق. `research/output/latest.json` يضم المعايير وبصمة البيانات والنتائج والقياسات. `results.csv` نسخة للتحليل المحلي فقط. فشل التغذية ينتج `status: unavailable` ولا يولد صفقات بديلة. هذا ليس ربحًا صفريًا.

GitHub Actions ينفذ يوميًا ويكتب التقرير على فرع `mirsad-paper-results` فقط. يستخدم توكن GitHub القصير العمر للنشر في المستودع نفسه، ولا يحتاج أسرارًا جديدة. الملف المنشور يحتوي أسعارًا عامة ومحاكاة فقط، ولا يتضمن بيانات حساب. تاريخ الشموع محدود بـ5000 شمعة؛ عند تجاوزه يتوقف التقرير حتى بدء دفعة محددة جديدة بدل إسقاط التاريخ بصمت.

## النقل إلى Google Sheets

المهمة المرتبطة بالشيت تقرأ التقرير من GitHub ثم تكتب صفوفًا جديدة بمعرفات ثابتة إلى «سجل النتائج». هذا نقل بواسطة المهمة المجدولة، وليس اتصالًا مباشرًا من الموقع إلى Drive. عند `status: unavailable` تبقي السجلات السابقة كما هي وتدوّن العائق. التقرير المتأخر أكثر من 36 ساعة لا يُعامل كتحديث ناجح.

ترتيب الأعمدة A:H ثم J:K: `id, batchId, strategyVersion, symbol, closedAt, currency, gross, fees` ثم رابط التقرير المثبت على commit وملاحظة «محاكاة بحثية؛ رسوم وانزلاق مفترضان». تحفظ صيغتي I وL. تُحوّل الأوقات إلى أرقام تاريخ بتوقيت الشيت. قبل الإدخال تُقارن المعرفات: المطابق لا يتكرر، والمعرف نفسه بنتيجة مختلفة يُحال للمراجعة دون الكتابة فوق الأصل. لا تُخلط الدفعات أو العملات ولا تُنقل المراكز المفتوحة كسجلات مغلقة.

المصدر الرسمي: https://developer.revolut.com/docs/api/revolut-x-crypto-exchange . البيانات العامة لا تتطلب مصادقة، والشموع منخفضة النشاط قد تستند إلى سعر منتصف العرض والطلب. نتائج هذا النموذج افتراضية لا تثبت جودة التنفيذ أو الربحية المستقبلية.
